description: "Thirteen interaction components, each built to do one thing well."

Every component installs the same way, ships as a single file you own, and takes
`inspect` for the outlined geometry plus (mostly) `onStateChange` for its
internal state.

```bash
npx moumenlab list
```

## Conventions

<ResponseField name="inspect" type="boolean" default="false">
  Available on every component. Outlines the geometry the component is reasoning
  about: measured boxes, anchors, and slots. This is what draws the blueprints on
  the site, and it is useful when a layout fights you.
</ResponseField>

<ResponseField name="onStateChange" type="(state) => void">
  Available on every component that has internal state worth watching. Fires with
  a typed snapshot on every change, so you can mirror it in a debug panel or
  assert against it in tests.
</ResponseField>

<ResponseField name="morph / animate / flip / drum" type="boolean" default="true">
  The motion switch, named after what that component actually does. Set it to
  `false` for a hard snap with no glides. Reduced motion is already handled
  through `<MotionConfig reducedMotion="user">`, so you do not need this prop for
  accessibility.
</ResponseField>
